### `public/data/processed/` (script outputs)

These files are generated by `scripts/process_data.py` and demonstrate the data manipulation pipeline. The dashboard computes the same transformations client-side, so these CSVs serve as reproducible offline evidence of the data manipulation process — a key deliverable for the datathon.

| File | Generated By | Purpose |
|------|-------------|---------|
| `master_county_dataset.csv` | `generate_master_dataset.py` | County-level analytical dataset (also shown in data viewer) |
| `county_water_summary.csv` | `process_data.py` | Per-county aggregated water + facility data |
| `risk_matrix.csv` | `process_data.py` | County counts by stress tier x facility bin |
| `pareto_ranked.csv` | `process_data.py` | Counties ranked by deficit with cumulative % |
| `distribution_comparison.csv` | `process_data.py` | Deficit % for industrial vs non-industrial counties |
| `sankey_flows.csv` | `process_data.py` | Sector-level flow data (explored, not in final dashboard) |
