### Dashboard Layout (top to bottom)
1. **Slim header** — Title + subtitle
2. **3 Insight cards** — Statewide Deficit, Counties with Unmet Needs, People at Risk
3. **Controls bar** — Region dropdown, Year dropdown (2020-2070), Color metric dropdown, Export CSV
4. **Interactive map** — Full-width, 550px desktop / 350px mobile
   - Data Centers overlay (ON by default)
   - Semiconductor Fabs overlay (ON by default)
5. **Sector breakdown bar** — Horizontal stacked bar showing demand % by sector
6. **Sankey Diagram** — "Where Does the Water Go?" (supply → sectors → met/deficit)
7. **Risk Matrix** — "Which Counties Are in Danger?" (5x4 heatmap: stress tiers x facility bins)
8. **Pareto Chart** — "How Concentrated Is the Problem?" (cumulative deficit + facilities)
9. **R² Regression Scatter** — "Is There a Statistical Link?" (facilities vs deficit, OLS line)
10. **Box Plot Distribution** — "Are Industrial Counties Worse Off?" (industrial vs non-industrial)
11. **Statewide Projection** — Supply/Demand/Deficit over 2020-2070
12. **Risk table** — Top 25 counties ranked by unmet need with deficit % severity coloring
13. **Footer** — Data attribution + GitHub link

### Map Features
- **Counties/Regions toggle** — Pill buttons to switch views
- **Counties view**: Per-county choropleth colored by selected metric (log-normalized), dark county borders
- **Regions view**: Same metric aggregated by region, same color scale, with:
  - Thick dissolved region boundary lines (2.5px dark overlay from `tx-regions.geojson`)
  - Near-invisible county borders within regions
  - Region letter labels at centroids
- **Gray-out**: Selecting a region grays out the rest of the state at ~75%
- **4 color metrics**: Water Needs (YlOrRd), Demand (Blues), Population (Purples), Supply (Greens)
- **Hover popups**: County name, region, population, demand, supply, needs
- **Custom HTML legend**: Gradient bar with tick labels
- **Data Centers overlay**: Blue diamond markers (31 facilities across 18 counties)
- **Semiconductor Fabs overlay**: Yellow star markers (138 facilities across 20 counties)

### Chart Methodologies (IE Frameworks)
All charts use Industrial Engineering analytical frameworks:
1. **Sankey** — Mass/flow balance analysis (process flow)
2. **Risk Matrix** — ISO 31000 risk assessment
3. **Pareto** — 80/20 rule (Juran's vital few)
4. **R² Regression** — OLS linear regression (R² = 0.054)
5. **Box Plot** — Comparative distribution analysis
6. **Projection** — Time-series trend analysis

Full methodology documented in `docs/METHODOLOGY.md`.

## Tech Stack

- **Frontend**: Vanilla HTML/CSS/JS (single file, no build step)
- **Charts**: Plotly.js 2.35.2 (CDN)
- **CSV Parsing**: PapaParse 5.4.1 (CDN)
- **Map**: Plotly `choroplethmapbox` with OpenStreetMap tiles (no API key)
- **Region boundaries**: Dissolved with shapely, served as static GeoJSON
- **Processing**: Python 3 (`scripts/process_data.py`)
- **Hosting**: Vercel (auto-deploy from GitHub)
- **Version Control**: GitHub (`ArathIndustries/datathon-water-analysis`)

## Key Data Findings

- **36 of 207** deficit counties hold **80%** of total statewide deficit
- **R² = 0.054** — weak linear correlation between facility count and water deficit
- Industrial counties average **21.7% deficit** vs **19.2%** for non-industrial
- **254** total counties, **31** data centers (18 counties), **138** semi fabs (20 counties)
- Deficit is highly concentrated (Pareto pattern), not uniformly distributed
